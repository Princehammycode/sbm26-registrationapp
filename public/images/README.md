# Images Directory

## Required Images

Please save the following images in this directory:

1. **flyer.jpg** - The Supernatural Breakfast Meeting flyer (orange/red background with Rev. Kwadwo Bempah)
2. **logo.png** - The Supernatural Breakfast Meeting logo (transparent background, gold/beige color)

## How to Add Images

1. Save the flyer image as: `flyer.jpg`
2. Save the logo image as: `logo.png`
3. Place both files in this directory: `c:\Users\Prince Hammond\Documents\sbm-recordapp\public\images\`

The application will automatically use these images for branding.
